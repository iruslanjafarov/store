# 🛍️ Store

Современный интернет-магазин с адаптивным интерфейсом, удобной навигацией и продуманной архитектурой. Проект разрабатывается с использованием Next.js, React и TypeScript.

---

## 🚀 Технологии

### Интерфейс
- **[Next.js](https://nextjs.org/)** — React-фреймворк.
- **[React](https://react.dev/)** — библиотека для построения пользовательских интерфейсов.
- **[TypeScript](https://www.typescriptlang.org/)** — статическая типизация и повышение надёжности кода.
- **[Tailwind CSS](https://tailwindcss.com/)** — CSS-фреймворк.
- **[Headless UI](https://headlessui.com/)** — доступные и гибкие UI-компоненты.
- **[Motion](https://motion.dev/)** — анимации и интерактивные переходы.

### Управление данными
- **[Zustand](https://zustand.docs.pmnd.rs/)** — управление глобальным состоянием приложения.
- **[Supabase](https://supabase.com/)** — работа с базой данных и API.

### Инструменты
- **[ESLint](https://eslint.org/)** — статический анализ и контроль качества кода.
- **[React Compiler](https://react.dev/learn/react-compiler)** — автоматическая оптимизация React-компонентов.
- **[Turbopack](https://turbo.build/pack)** — сборка и ускорение разработки.

## ✨ Фичи

- 🛒 Каталог товаров.
- 🔎 Поиск и фильтрация товаров.
- 📦 Карточки товаров с изображениями и ценами.
- 📱 Адаптивный пользовательский интерфейс.
- 🎨 Современный минималистичный дизайн.
- ⚡ Быстрая работа благодаря Next.js и Turbopack.
- 🧩 Компонентная архитектура.
- 🔄 Управление состоянием через Zustand.

---

## 🎯 Цели

Основная цель проекта — разработка полноценного интернет-магазина с акцентом на:

- Чистую и масштабируемую архитектуру.
- Переиспользуемые React-компоненты.
- Типобезопасность с TypeScript.
- Удобный UX/UI.
- Производительность и оптимизацию.
- Практическое применение современного frontend-стека.
